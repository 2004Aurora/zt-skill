# zt-skill

枕棠 AI 超级个体的公开 Skill 入口库。

这里放基础能力、公开方法、通用模板和可复用示例，帮助更多人理解 Skill 如何服务内容创作、知识整理和个人成长。

## 内容边界

- 公开、低风险、可独立运行的基础 Skill
- 通用安装方法、配置模板和示例
- 脱敏后的工作流与方法论
- `zt-skill-pro` 付费专属库的产品介绍

核心交付包、私教工作流、内部配置和持续更新内容不放在本仓库。付费版入口：`zt-skill-pro`。

## 使用原则

请在使用任何 Skill 前阅读对应说明，保护个人隐私，不要提交 API Key、Cookie、Token、密码、微信聊天原文或其他敏感资料。

本仓库内容仅供学习和合法用途使用。具体 Skill 的许可、前置条件和限制，以各自目录中的说明为准。
